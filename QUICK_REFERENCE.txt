No configuration changes required! The system uses existing config:

1. Run tests:

3. Verify session reset:

TROUBLESHOOTING:
================

Q: Same photo showing twice?
A: This should not happen. If it does, check that session_hash_tracker
   is properly imported and called in routes.py

Q: Photos not advancing?
A: Check that pick_file() is working and cache is built
   Check server logs for [SessionHashTracker] debug messages
   Verify session_id is in photo state cookie

Q: Session not persisting after refresh?
A: Cookie settings in routes.py persist_photo_state():
   - max_age=60*60*24*365 (1 year)
   - secure=True when HTTPS
   - samesite="None" when HTTPS, "Lax" otherwise
   Browser's privacy settings might delete cookies

Q: Error importing session_hash_tracker?
A: Ensure app/session_hash_tracker.py exists
   Check that imports in routes.py match function names exactly

  - Expired session: {session_id}
  - Reset session: {session_id}
