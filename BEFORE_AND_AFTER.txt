BEFORE: The Problem
===================

Code Flow (OLD):
  
  @G.app.route("/random")
  def random_image():
      path = pick_file(G.PHOTO_ROOT)        # ← Pick photo
      state = get_photo_state()              # ← Read state from cookie
      
      # ... process image ...
      
      return persist_photo_state(response, state)  # ← Write SAME state back
                                                    #   (no changes!)

Issue:
  ❌ photo_index never incremented
  ❌ photo_served never incremented
  ❌ Cookie never changed
  ❌ Client can't track progress
  ❌ Some clients stuck on first photo

Result:
  Client Request 1-5: Get photo 1 (server doesn't track it was shown)
  Client Request 6-10: Get photo 1 again (server doesn't know it was shown)
  Client Request 11-N: Keep getting photo 1 (forever stuck)
  😞 Broken rotation


AFTER: The Solution
====================

Code Flow (NEW):

  @G.app.route("/random")
  def random_image():
      state = get_photo_state()
      session_id = state.get("session_id")           # ← New: Get session ID
      register_session(session_id, random_pool_size)  # ← New: Register session
      
      cycle_phase = get_cycle_phase(session_id)      # ← New: Check phase
      
      if cycle_phase == "same_day":                  # ← New: Phase logic
          path = pick_file(G.PHOTO_ROOT, state)      
          if path and not has_same_day_photo_been_served(...):
              mark_same_day_photo_served(...)         # ← New: Mark as served
          else:
              transition_to_random_phase(...)         # ← New: Transition
      
      elif cycle_phase == "random":                  # ← New: Random phase
          if should_transition_to_same_day_phase(...):
              transition_to_same_day_phase(...)
          else:
              mark_random_photo_served(...)           # ← New: Track random
      
      return persist_photo_state(response, state)

Features:
  ✓ Session ID uniquely identifies browser
  ✓ Phase tracking ensures proper cycling
  ✓ MD5 hashes prevent duplicates
  ✓ Automatic phase transitions
  ✓ State properly managed and persisted

Result:
  Client Request 1-5: Get same-day photos 1-5 (marked as served)
  Client Request 6: Exhausted same-day → transition to random
  Client Request 7-106: Get 100 random photos (counter increments)
  Client Request 107: Quota reached → transition back to same-day
  Client Request 108-112: Get same-day 1-5 again (tracking reset)
  😊 Proper cycling forever
