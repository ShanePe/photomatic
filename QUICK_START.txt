TLDR - What Was Done:
=====================

Problem: Some clients stuck on first photo in rotation
Solution: Added session-based tracking with cycle phases
Result:   Photos now cycle properly through today's photos, then random, repeat


New System Flow:
================

1️⃣  Show all TODAY'S PHOTOS sequentially (Phase 1: same_day)
2️⃣  Show N RANDOM PHOTOS (Phase 2: random, N = config value)
3️⃣  Repeat forever

Each browser gets unique session_id (UUID) stored in cookie.
Server tracks which photos shown via MD5 hash to prevent duplicates.

GETTING STARTED (5 MINUTES):
=============================

1. VERIFY FILES EXIST:
   ls -la app/session_hash_tracker.py
   ls -la tests/test_session_hash_tracker.py
   
2. RUN TESTS:
   pytest tests/test_session_hash_tracker.py -v
   
   Expected output:
   test_register_session PASSED
   test_cycle_phase_transitions PASSED
   test_same_day_photo_tracking PASSED
   test_random_photo_counting PASSED
   test_reset_session PASSED

3. START APPLICATION:
   python -m app.wsgi
   
4. OPEN BROWSER:
   http://localhost:5000/
   
5. WATCH PHOTOS CYCLE:
   • First 5 requests: Same-day photos
   • Next 100 requests: Random photos
   • After 100: Back to same-day
   • Check server logs for [SessionHashTracker] messages

6. TEST PERSISTENCE:
   • Refresh page (Ctrl+R)
   • Session should continue from same position
   • Session_id should be same in browser cookie


CONFIGURATION (Optional):
==========================

Adjust cycle ratio in config.yaml:

  cache:
    same_day_cycle: 100   # Number of random photos per cycle

Examples:
  • 50:  More same-day photos (cycle every 50 random)
  • 100: Balanced (default)
  • 300: More random photos (mostly random with occasional same-day)


TROUBLESHOOTING (Quick Fixes):
==============================

❌ Photos still stuck on first:
   → Check session_id in browser cookie (DevTools > Application > Cookies)
   → Check server logs for [SessionHashTracker] messages
   → Restart application

❌ Phase not transitioning:
   → Check same_day_cycle config value
   → Verify photo library has both same-day and random photos
   → Look for transition log messages

❌ Tests failing:
   → Ensure app/session_hash_tracker.py exists
   → Check imports are correct
   → Run with: pytest -vv for detailed output

❌ Import errors:
   → Verify app/session_hash_tracker.py is in app/ directory
   → Check routes.py has correct imports:
     from .session_hash_tracker import (...all functions...)
